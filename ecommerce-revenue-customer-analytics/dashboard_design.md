# Power BI Dashboard Design

## Executive Overview
Cards: Net Revenue, Orders, AOV, Return Rate, Repeat Customer Rate.
Charts: monthly revenue, category revenue, regional sales and return rate.

## Customer Analytics
RFM segment distribution, segment revenue, repeat-customer trend and cohort matrix.

## Product and Returns
Product/category revenue, return rate, discount impact and drill-through table.

Slicers: date, region, category and RFM segment.
