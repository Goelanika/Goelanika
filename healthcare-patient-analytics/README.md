# Healthcare Patient Analytics

A beginner-friendly Data Analyst project focused on patient visits, waiting time, readmissions and department-level performance.

## Tools used

- Python (Pandas, NumPy, Matplotlib)
- SQL
- Microsoft Excel
- Power BI
- Tableau

## Project workflow

1. Generate a reproducible synthetic patient dataset.
2. Clean missing, duplicate and inconsistent records in Python.
3. Perform exploratory data analysis (EDA) for patient visits, waiting time, readmission rate and department trends.
4. Use SQL queries to calculate operational KPIs and compare departments.
5. Prepare dashboard-ready outputs for Power BI and Tableau.
6. Summarize the main findings in a simple business-friendly format.

## Main KPIs

- Total patient visits
- Average waiting time
- Readmission rate
- Department-wise patient volume
- Average length of stay
- Patient satisfaction score

## Files

- `analysis.py` - generates, cleans and analyzes the dataset
- `healthcare_analysis.sql` - SQL queries for core healthcare KPIs
- `dashboard_notes.md` - suggested Power BI and Tableau dashboard layout
- `requirements.txt` - Python dependencies

## Data note

This project uses synthetic data created for learning and portfolio purposes. It does not contain real patient information.
